### Featured project

#### [Demoflow — population dynamics in Python](https://github.com/tillingspore/demoflow)

An experimental Python library for composing population-dynamics models and running reproducible numerical simulations.

- **Modeling:** exponential and logistic growth, competition, Lotka–Volterra, structured populations, and integral projection models.
- **Numerical methods:** Euler, Runge–Kutta (RK4), SciPy-based solvers, and stochastic simulation.
- **Engineering:** validated configurations, a CLI, data export, automated tests, static checks, and continuous integration.

**Explore:** [Source code](https://github.com/tillingspore/demoflow) · [Documentation](https://github.com/tillingspore/demoflow/tree/main/docs) · [Examples](https://github.com/tillingspore/demoflow/tree/main/examples)
